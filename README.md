# ICDE Dataset

This repository provides the datasets associated with **Imagery-based Commuting Distance Estimation (ICDE)**, a framework for estimating regional average commuting distance from satellite imagery and geographic neighbourhood information.

The dataset covers **179 administrative regions in Beijing, China**.

## Dataset Contents

| File / Directory | Description |
|---|---|
| `boundaries.gpkg` | Geographic boundaries of the study regions |
| `label.csv` | Regional average commuting distances (km), derived from Wi-Fi mobility observations |
| `census/` | Regional census data |
| `poi/` | Regional point-of-interest (POI) data |

## Satellite Imagery

Satellite imagery was obtained from
[Esri World Imagery Wayback](https://livingatlas.arcgis.com/wayback/).

The imagery is not redistributed in this repository
due to third-party licensing restrictions.
